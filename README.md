# Простой эмулятор командной оболочки Unix, написанный на C++ для Windows. Вариант 14.

# Описание
Программа имитирует базовое поведение командной строки Unix (bash).  
Реализованы приглашение вида user@user:~$,
вывод стартового сообщения и поддержка нескольких команд

# Требования
1. ОС: Windows
2. Компилятор с поддержкой C++11 и выше (MSVC, MinGW)
3. Кодировка консоли с поддержкой кириллицы (setlocale(LC_ALL, "Russian"))

# Поддерживаемые команды
```
ls [аргументы] - Выводит переданные аргументы в строку (эмуляция).
cd [аргументы] - Выводит переданные аргументы в строку (эмуляция).
exit [код] - Завершает работу программы. Если аргумент не число — выводит сообщение об ошибке и завершается.
[любая другая] -  Выводит bash: <команда>: command not found.
```
# Структура кода
```
command_prompt() — выводит приглашение username@username:~$  
ls(), cd() — заглушки, возвращают введённые аргументы  
kill() — обрабатывает команду exit, включая проверку числового аргумента  
not_found() — сообщение о неизвестной команде  
main() — основной цикл чтения и диспетчеризации команд  
```
# Пример работы
```
To run command as administrator (user "root"), use "sudo <command>".  
See "man sudo_root" for details.  
user@user:~$ ls -la  
ls -la  
user@user:~$ exit 0  
exit 0  
```
